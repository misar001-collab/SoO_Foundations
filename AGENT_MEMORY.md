# Agent Memory

Purpose: persistent collaboration preferences for agentic AI working in this repo.

Last updated: 2026-02-22

## User Preferences
- Keep project structure valid; avoid unnecessary refactors.
- If current structure is already valid, do not change it.
- Prefer practical scripts and visuals for presentation/demo use.
- Keep documentation current (`README.md`, `PROGRESS.md`) when workflows change.
- Use clear runnable commands for Windows/PowerShell.
- Add comments/documentation heavily when requested.
- From now on, heavily comment all scripts by default (unless user explicitly asks for minimal comments).
- For every script, include a high-level top-of-file comment block explaining what it does.
- Assume user is non-expert in this domain; comments should explain what is happening and why in plain language.

## Communication Preferences
- Be direct and concise.
- Focus on actionable next steps.
- Confirm outcomes after changes (for example: tests, generated artifacts).

## Workflow Preferences
- Stage-by-stage execution is preferred.
- For new stage work, define concrete deliverables and measurable outputs.
- For visual validation, provide exportable image outputs in `results/`.

## Update Rules
- Append new confirmed preferences; do not delete older ones unless explicitly replaced.
- Keep this file short and high signal.
- Treat this file as repo-local memory, not global memory.
